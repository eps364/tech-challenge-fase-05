# Skill Catalog

Load the smallest skill that matches the task. Skills complement `AGENTS.md`;
they do not override the product specification.

| Skill | Use When | Do Not Use As |
| --- | --- | --- |
| `aps-product` | Changing scope, requirement, narrative, acceptance criteria, or project documentation. | A substitute for technical design. |
| `java-clean-architecture` | Modifying Java, REST, JPA, Flyway, use cases, or gateways. | Permission to expand the MVP. |
| `data-ethics` | Handling indicators, demo data, analytics, dashboards, or outcome claims. | A clinical decision protocol. |
| `quality-and-demo` | Testing, coverage, Docker, Swagger, Bruno, Insomnia, or hackathon walkthroughs. | A replacement for product acceptance criteria. |

For a feature that crosses areas, read `aps-product` first, then add the
technical or quality skill required by the change.
