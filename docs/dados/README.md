# Dados e analises

Esta area registra a evidencia usada para escolher o problema do MVP. Os dados
sao territoriais e agregados; os achados indicam pontos para validacao local e
nao provam causalidade, qualidade clinica ou risco individual.

- [Fontes oficiais](fontes-oficiais.md): origem, periodo, hash, cobertura e
  limitacoes dos arquivos utilizados.
- [Atualizacao de fontes](atualizacao-fontes-oficiais-2026-07-18.md): auditoria
  da troca para as estimativas municipais do IBGE de 2025.
- [Plano de analise Python](plano-analise-python.md): metodo reproduzivel.
- [Oportunidades descobertas](oportunidades-descobertas.md): leitura inicial
  das oportunidades e cuidados de interpretacao.
- [Matriz de problemas candidatos](matriz-problemas-candidatos.md): comparacao
  das alternativas avaliadas.
- [Sintese APS](sintese-oportunidades-aps.md) e [sintese de leitos](sintese-oportunidades-leitos.md): resultados resumidos por frente analitica.

Os scripts, dados processados e relatorios completos estao em
[`analytics/`](../../analytics/README.md) e `data/`.
