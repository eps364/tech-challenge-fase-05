# Produto

O MVP ajuda a coordenacao de APS a responder: "qual territorio deve receber
uma acao de busca ativa primeiro, e por qual motivo?". A unidade de
priorizacao e sempre territorial ou uma UBS, nunca uma pessoa.

- [Especificacao de requisitos](especificacao-requisitos.md): escopo,
  requisitos, regras de negocio e criterios de aceite.
- [Caso tangivel de Joao](caso-tangivel-joao.md): exemplo ficticio que torna a
  lacuna operacional compreensivel sem transformar uma pessoa em dado do
  produto.
- [Storytelling da solucao](storytelling-da-solucao.md): narrativa para a
  demonstracao, limites e evidencia tecnica observavel.
