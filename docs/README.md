# Documentacao do SUS-Connect APS

Este indice organiza os materiais ativos do MVP de priorizacao territorial de
busca ativa na Atencao Primaria a Saude. O sistema usa sinais agregados para
apoiar uma decisao operacional; ele nao gerencia pacientes nem faz previsoes
clinicas.

| Area | Conteudo principal |
| --- | --- |
| [Contexto](contexto/README.md) | Enunciado e checklist do hackathon. |
| [Produto](produto/README.md) | Problema, requisitos, caso tangivel e narrativa da solucao. |
| [Dados](dados/README.md) | Fontes oficiais, metodo, limitacoes e analises reproduziveis. |
| [Tecnico](tecnico/README.md) | Arquitetura, API, ambiente local e evidencia E2E. |
| [Apresentacao](apresentacao/README.md) | Deck HTML e roteiro de pitch. |

Os arquivos de processamento e os relatorios analiticos gerados ficam em
[`analytics/`](../analytics/README.md). Dados brutos e processados ficam em
`data/` para preservar a trilha de reproducao.
